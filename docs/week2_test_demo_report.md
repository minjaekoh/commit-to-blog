# Week2 테스트/데모 완료 정리

## 1) 핵심 3개 사용자 플로우 E2E 점검

### 플로우 A: 저장소/커밋 선택
1. 클라이언트에서 저장소 목록 로드
2. 저장소 선택 시 커밋 목록 로드
3. 커밋 선택 시 diff 파일 수 표시

판정 기준:
- `GET /api/repos`, `GET /api/commits`, `GET /api/diff` 응답 성공
- UI에서 로딩/에러/빈 상태가 정상 분기됨

결과: 통과

### 플로우 B: AI 인터뷰 진행
1. 인터뷰 시작(`POST /api/interview/start`)
2. 답변 제출(`POST /api/interview/:sessionId/answer`)
3. 힌트/해설/스킵 액션 확인

판정 기준:
- 세션/턴 생성 및 상태 전이 확인
- 각 액션 응답 payload 정상

결과: 통과

### 플로우 C: 초안 생성/수정/저장/재편집
1. 인터뷰 결과 분기별 초안 생성(답변성공/모르겠어요/스킵)
2. 마크다운 편집 + 프리뷰 확인
3. 저장(`POST /api/posts`) 후 목록 조회(`GET /api/posts`)
4. 카드 선택 후 재편집

판정 기준:
- 분기별 초안 내용 차등 생성
- 저장 후 목록에 노출되고 재편집 가능

결과: 통과

## 3) 데모 시나리오 준비

### 실사용 레포 시나리오
- 레포: 본인 실제 프로젝트 레포 1개
- 시나리오:
1. 의미 있는 커밋 선택
2. 인터뷰 답변 제출 후 피드백 확인
3. 초안 저장 및 재편집 시연

### 백업 샘플 시나리오
- 레포: 커밋 이력이 안정적인 백업 레포 1개
- 시나리오:
1. 스킵 분기 시연
2. 해설 분기 시연
3. 저장 목록/재편집 시연
